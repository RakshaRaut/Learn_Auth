# Node.js Backend Starter

##  Getting Started

### 1. Initialize project

```bash
npm init -y

2. Install required dependencies

npm install express cookie-parser mailtrap bcryptjs dotenv jsonwebtoken mongoose crypto

📦 Dependencies Explained

    express
    Minimal and flexible Node.js web application framework for building APIs and web apps.

    cookie-parser
    Middleware to parse cookies attached to the client request object.

    mailtrap
    Used to test email sending in development; routes emails to a fake SMTP inbox.

    bcryptjs
    Library for hashing passwords securely using the bcrypt algorithm.

    dotenv
    Loads environment variables from a .env file into process.env, keeping sensitive credentials out of code.

    jsonwebtoken
    Used to create and verify JSON Web Tokens (JWT) for authentication and authorization.

    mongoose
    ODM (Object Data Modeling) library for MongoDB; helps in managing schemas and interacting with the database.

    crypto
    Built-in Node.js module used for encryption, hashing, and other cryptographic operations.
```
